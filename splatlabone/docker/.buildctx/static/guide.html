Pipeline overview

Ingest → SfM (GLOMAP/COLMAP) → optional geometry (VGGT-X, DA3) → train (3DGS/2DGS+MCMC) → export.

SfM ──► Geometry? ──► gsplat train ──► .splat / .ply

GLOMAP

Fast global mapper — best NVS for dense photo sets on Olares One (24-core CPU matching + GPU).

VGGT-X

Memory-efficient VGGT for COLMAP-free pose + depth. Used in robust preset with 2DGS+MCMC.

2DGS vs 3DGS

2DGS (surfels) improves geometry on hard scenes. 3DGS is default for quality preset.

MCMC densification

Handles noisy feed-forward initialization — pair with VGGT-X / DA3 front-ends.

Depth Anything 3

CC BY-NC on Giant model — fast preview only if license OK. Use GLOMAP+gsplat for commercial.

Realtime modes

  • geometry_preview — WS frame ingest, coarse point cloud in seconds
  • progressive_splat — gsplat checkpoints every N iters, viewer hot-reload

Building the runtime image

  1. Install dockerbuilderone on Olares; add its MCP in Cursor
  2. Zip splatlabone/docker/ (Dockerfile at zip root)
  3. upload_project("splatlabone", zip_base64)
  4. start_build("splatlabone", "ghcr.io/coynntis/splatlabone:1.0.0", "Dockerfile")
  5. Set GITHUB_TOKEN on splatlabone for ghcr pull

MCP for agents

SplatLab MCP at /mcp/mcp — ingest, create_job, get_scene_urls. Image builds use dockerbuilderone MCP, not SplatLab.

Olares One constraints

  • RTX 5090M 24 GB VRAM — chunk dense VGGT/DA3 runs
  • PyTorch cu128 + gsplat CUDA 12.8 for sm_120
  • 96 GB RAM — GLOMAP CPU matching benefits from 16 threads
